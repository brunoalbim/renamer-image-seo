# 🚀 WordPress Media Renamer & SEO Alt Text Plugin  

Um plugin simples e eficiente que melhora o **SEO das mídias** no WordPress ao **renomear automaticamente** os arquivos enviados e definir um **alt text** otimizado.

## ✨ Funcionalidades  

✅ **Renomeação automática de mídias** – Ajusta o nome do arquivo para um formato otimizado para SEO.  

✅ **Geração automática de atributo "alt"** – Define um texto alternativo (alt text) baseado no nome da mídia.  

✅ **Código leve e eficiente** – Apenas um arquivo PHP, sem dependências externas ou configurações complexas.  

✅ **Melhoria de SEO sem esforço** – Tudo acontece automaticamente no momento do upload.  

---

## 🔧 Instalação  

1. Baixe o arquivo PHP do plugin.  
2. Acesse o painel do WordPress e vá para **Plugins > Adicionar Novo**.  
3. Clique em **Fazer upload do plugin** e selecione o arquivo.  
4. Instale e ative o plugin.  

✅ **Pronto!** Agora todas as imagens enviadas serão renomeadas automaticamente e receberão um **alt text** otimizado.  

---

## ⚙️ Como Funciona  

O plugin intercepta o upload de mídias no WordPress e realiza as seguintes ações:  

- **Renomeia o arquivo** utilizando um formato amigável (sem caracteres especiais e espaços).  
- **Define o atributo "alt"** da imagem com base no nome limpo do arquivo.
